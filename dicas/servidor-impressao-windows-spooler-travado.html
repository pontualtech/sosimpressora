Spooler de impressão Windows Server travado: como destravar

SOS Impressora30 anos de bancadaMaio/2026

Spooler travado em servidor Windows = empresa inteira sem imprimir. Cenário crítico em final de mês ou impressão de relatórios urgentes. Procedimento abaixo é o que TI sênior faz em produção.

1Reiniciar serviço Print Spooler

Solução mais simples — funciona em em muitos casos.

  1. RDP no Windows Server.
  2. Win + R → services.msc → Enter.
  3. Localize "Print Spooler" (ou "Spooler de Impressão").
  4. Clique direito → Reiniciar.
  5. Tente imprimir — fila deve liberar.
  6. Se serviço PARA imediatamente após reiniciar = corrupção do print queue.

2Limpar fila de impressão corrompida

Job impressão corrompido trava spooler em loop. Apagar manualmente resolve.

  1. Pare serviço Print Spooler primeiro (services.msc).
  2. Abra explorer → C:\Windows\System32\spool\PRINTERS.
  3. DELETE TODOS os arquivos.spl e.shd dessa pasta.
  4. Reinicie serviço Print Spooler.
  5. Imprima teste — deve funcionar.

3Verificar drivers corrompidos

Driver de impressora corrompido pode derrubar spooler inteiro.

  1. Print Management Console (printmanagement.msc).
  2. Drivers → identifique driver suspeito (geralmente o último adicionado).
  3. Remova driver problemático.
  4. Reinicie spooler.
  5. Reinstale driver atualizado do fabricante.

4Auditar logs do Event Viewer

Causa raiz aparece nos logs.

  1. Win + X → Visualizador de Eventos.
  2. Logs do Aplicativo + Logs do Sistema.
  3. Filtre por Source: "Microsoft-Windows-PrintService".
  4. Erros recentes apontam: driver problemático, impressora offline, ou DLL corrompida.

5Patch do Windows Server

Microsoft lançou patches específicos pra Print Spooler em 2024 (CVEs PrintNightmare).

  • Windows Update — instalar patches mensais.
  • Verificar se PrintNightmare patches aplicados (KB5005010, KB5005033).
  • Reiniciar servidor após updates.

6Restart agendado preventivo

Em ambientes críticos, reiniciar serviço spooler diariamente previne travamento.

  1. Agendador de Tarefas → Nova Tarefa.
  2. Trigger: 02:00 todo dia.
  3. Ação: net stop spooler && timeout 5 && net start spooler.
  4. Reduz incidentes de travamento em ~80%.

Em servidor crítico, spooler travado = chamado urgência. Atendemos remotamente (RDP/AnyDesk) em SP capital — diagnóstico rapidamente, resolução geralmente em <2h. SLA empresarial inclui prevenção via monitoring (Zabbix, PRTG).
